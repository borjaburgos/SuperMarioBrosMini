<p>GB Studio project for the Super Mario Bros demake, made to showcase the dynamic tiles/metatiles plugin.</p>
<p><strong>Editor requirement:</strong> GB Studio 4.3.2 or newer in the 4.3 release line. The project resources and bundled engine plugins have been migrated for the released 4.3 engine.</p>
<p>You can download a compiled ROM from the releases.</p>
